# CRAG Generated-Answer Evaluator Mapping

This diagnostic records whether sanitized generated-answer metrics can be mapped to a CRAG local evaluator result class.

Local evaluator inputs remain outside Git because they may require raw questions, labels, or generated answers. Public artifacts include only IDs, hashes, counts, aggregate scores, and mapping result classes.

This does not grant redistribution rights for CRAG raw data and does not claim human validation or official platform benchmarking.
