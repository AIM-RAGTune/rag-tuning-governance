# CRAG Evaluator Mapping v2

CRAG evaluator mapping v2 diagnoses whether generated answers can be scored locally while keeping raw CRAG questions, source documents, API responses, prompts, and generated answers out of the public repository.

Public artifacts contain only hashes, ids, score columns, aggregate diagnostics, and blocked/result classes. If local CRAG data or evaluator schema mapping is unavailable, the diagnostic reports an explicit blocked class.
