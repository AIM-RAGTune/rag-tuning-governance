# Public Repository Note

This public repository was created from the sanitized current tree of the private publication review repository using a fresh one-commit history.

It intentionally does not include:

- prior private Git history;
- raw CRAG datasets;
- raw CRAG question text;
- raw source documents;
- raw API responses;
- credentials or private local paths.

The historical validation ledger in `results/historical/` is a sanitized evidence summary, not a raw artifact dump. It preserves positive, negative, inconclusive, blocked, refused, and engineering-only findings without redistributing licensed dataset text.
