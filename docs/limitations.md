# Limitations

- CRAG mock-API governance superiority is the strongest current result, not a universal proof.
- RAG Compass ranked 5th in the strongest CRAG mock-API result; optimizer superiority is unsupported.
- RAGBench HotpotQA is context-retrieval eligible, not full corpus-backed.
- Human-eval and generative LLM validation remain unsupported.
- Official external platform benchmarking has not been run.
- Raw licensed datasets are not redistributed.
