# Results

This directory contains processed summary tables for scientific review. Raw logs, raw datasets, raw CRAG question text, raw source passages, and raw API responses are not included. CRAG case and sample artifacts use hashes, IDs, metrics, and sanitized non-reconstructive summaries.

See `historical/` for the sanitized historical evidence ledger, including positive, negative, inconclusive, blocked, refused, and engineering-only results.
