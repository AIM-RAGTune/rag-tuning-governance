\section{Behaviorally Distinct Policy Experiment}
The follow-up experiment reanalyzes sanitized CRAG mock-API frozen observations using candidate policies with different endpoint-routing and operating-cost behavior. The primary endpoint is not a scalar weighted utility difference: governed selection must either reduce measured cost or latency at equivalent proxy-plus-evidence quality, or improve quality under a fixed deployment budget. The current result is \texttt{GOVERNANCE\_REDUCES\_COST\_AT\_EQUIVALENT\_QUALITY}: governed selection chose \texttt{low\_retrieval\_single\_endpoint}, while quality-only selection chose \texttt{optuna\_tpe}. This remains frozen-observation source/retrieval evidence and does not establish human-calibrated, generative, production, or RAG Compass superiority claims.

\section{Fresh Live CRAG and HotpotQA Extension}
The next phase attempts to run the behaviorally distinct governance design against a fresh live CRAG mock-API collection and HotpotQA as an alternate public corpus with answer labels and supporting facts. In the current public repository execution, fresh CRAG ran as a sanitized live sample but remained blocked because the quality signal was unusable. HotpotQA produced an operational-gain-with-quality-loss non-generative result. These results do not upgrade frozen-observation evidence to replicated evidence.

\section{Generative LLM Validation}
RAGTune Generative LLM Validation v1 adds pinned-generator answer generation with sanitized generated-answer metrics. The current public artifact set includes a bounded local Ollama \texttt{qwen3:8b} run on HotpotQA with no committed raw prompts or generated answers. The result is directional because CRAG generative validation remains blocked or incomplete.

\section{Limitations}
Broad generative LLM validation beyond the bounded local HotpotQA run is unsupported. Human evaluation is not yet run. Official external-platform benchmarking is not yet run. Production readiness is not claimed.

\section{Reproducibility}

Current evidence supports continued RAGTune governance investigation more than optimizer-specific claims about RAG Compass.
