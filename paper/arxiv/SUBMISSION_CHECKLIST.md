# arXiv Submission Checklist

1. [ ] Build and inspect the LaTeX manuscript and vector figures.
2. [ ] Confirm the arXiv abstract character count at upload.
3. [ ] Obtain arXiv endorsement if required.
4. [ ] File the Fairview conflict-of-interest disclosure before the final submission timestamp.
5. [ ] Submit the paper to arXiv.
6. [ ] Update the published preprint's Code link to the canonical repository URL if the external publication record still points to the legacy URL.

All listed items are human-only submission steps and are intentionally unchecked.
